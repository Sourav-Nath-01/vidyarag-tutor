How it works

  1. Your questionplain English
  2. Dense + sparseBGE-large vectors (FAISS) and BM25 keywords
  3. FusionReciprocal Rank Fusion
  4. RerankMiniLM cross-encoder
  5. The momentbest passage per lecture, with timestamp
  6. The answeran LLM writes only from those passages and cites them; the server checks every citation

Lectures were transcribed with Whisper and slides read with Tesseract OCR. Passages follow slide changes detected from OCR similarity. If the lectures don't cover a question, the tutor says so instead of guessing.
