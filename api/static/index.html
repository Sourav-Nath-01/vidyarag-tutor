How an answer is made

Search first. The model only writes from what it was shown.

Every lecture was transcribed with Whisper and its slides read with Tesseract OCR, then split wherever the slide changes. Each passage is one slide's worth of explanation, with its own timestamp.

  1. 01

    Retrieve

    Your question is matched against 16,050 passages two ways: BGE-large embeddings in FAISS for meaning, and BM25 for exact terms.

  2. 02

    Rerank

    Reciprocal Rank Fusion merges both lists. A cross-encoder then reads each candidate against your question and keeps the best moment from each lecture.

  3. 03

    Gate

    If even the best passage is a weak match, the tutor says the lectures don't cover it. The language model is never called, so it has nothing to guess from.

  4. 04

    Answer

    gpt-oss-20b writes from the top five moments only, and has to cite every factual sentence with the moment it came from.

  5. 05

    Verify

    The server checks that each citation points to a real source and reports how much of the answer is cited. Click a citation to watch that moment.
